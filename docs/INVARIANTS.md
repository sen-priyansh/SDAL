SDAL Invariants

1. Content-addressable storage using a Merkle DAG is mandatory.
2. Change mapping must work for binaries and large files.
3. Global Static files exist and are enforced when declared.
4. Rules may be disabled, but must be architecturally supported.
5. The core must be modular.
6. Ledger (append-only) capability must be possible later.
7. Rust is the only implementation language.
